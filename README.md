# LO API — заказы Лента B2B через API

`lo-order` проводит B2B-заказ на тестовом стенде Ленты целиком, минуя веб-морду
и мобильные приложения сотрудников: от корзины покупателя до доставки.

## Что умеет

**Оформление заказа** — доставкой или самовывозом. Вход в аккаунт, выбор
организации, адреса доставки или магазина самовывоза, наполнение корзины,
собственные нужды, способ оплаты, интервал и создание заказа.

**Вывод на смену** сборщика и курьера — без них заказ некому назначить.

**Назначение заказа** на сборщика и курьера в TMS. Если заказ уже назначен,
этот шаг пропускается.

**Сборка** — за сборщика, всех типов позиций: штучных, весовых, партионных,
маркированных (ПЭУ и ОСУ), проб, заказов в собственные нужды. С проверкой в
SAP и упаковкой. Прерванная сборка продолжается с того места, где
остановилась.

**Доставка** — за курьера, до статуса «Доставлен». Самовывоз завершается
сборкой.

**Генерация марок** Datamatrix для товара — по SKU или штрихкоду.

**Повтор заказа по номеру** — те же товары, адрес или магазин и оплата, на
сегодня. Весовой товар повторяется теми же порциями.

**Повтор прошлого заказа** — те же ответы без вопросов.

Работает с несколькими стендами (test12, operation), настройки каждого лежат
в `env/`.
